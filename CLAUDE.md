## Commands

- Test: `npm test`
- Typecheck: `npm run typecheck`
- Build: `npm run build`
<!-- claude-kit:end id=commands -->

<!-- claude-kit:begin id=done v=0.8.1 sha=46b82269 -->
## Definition of done

Before you say a change is done, run `npm run typecheck && npm test` and fix every failure.
If you could not run it, say so instead of reporting success.
